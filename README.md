# Employee Performance and Productivity Analysis

This project is a detailed analysis of employee performance and productivity using tools like **Excel**, **Power BI**, and **MySQL**. The goal was to understand how factors like work hours, training, salary, and job satisfaction influence employee performance and help identify areas for improvement.

## What This Project Covers ?

I explored a dataset (sourced from Kaggle) that includes employee details like department, age, salary, training hours, performance scores, and resignation status. The analysis focused on:

- Department-wise performance trends  
- Impact of work hours and overtime on productivity  
- Training effectiveness  
- Employee satisfaction across departments  
- Resignation and retention patterns

## Tools Used :

- **Microsoft Excel** – For data cleaning and formatting
- **Power BI** – To create dashboards and visualize insights
- **MySQL** – To perform data analysis through queries

##  Insights:

- Performance is not strongly tied to education level — Master's and Bachelor's holders performed similarly.
- Working more than 50 hours/week didn’t improve performance, suggesting that overwork might hurt productivity.
- Training hours had minimal impact, meaning quality may matter more than quantity.
- Finance and HR had the highest resignation rates, possibly needing better retention strategies.
- Engineering had the highest average salary and lowest resignation rate, making it the most stable department.
